# MiniDB 界面设计稿 v2

一套**可交互的静态设计稿**（纯 HTML / CSS / JS，无构建、无依赖），用来在改 Go 界面代码之前先选定方向。

## 打开方式

```bash
cd docs/design/v2
python3 -m http.server 8777     # 然后访问 http://localhost:8777/index.html
```

（直接双击 `index.html` 也能看大部分内容，但浏览器可能因 `file://` 限制拦截部分资源。）

## 里面有什么

| 区域 | 内容 |
| --- | --- |
| 顶部控制条 | 三套方案（A 精炼工作台 / B 轨道 / C 阿特拉斯）× 四个主题（浅色 / 深色 / 纸墨 / 极光）× 六种强调色，实时切换 |
| 应用页面 | 欢迎页（三种形态）、项目概览、数据（含 DDL / 文档标签）、表结构、查询、执行计划、结果图表、ER 图、监控、导出与导入（各四步向导）、用户与权限、AI 助手、行预览 |
| 设计系统 | 现状审计、三套方案对比、令牌、Logo、动效实验室、场景与状态、做选择 |
| 弹层 | 命令面板（⌘K）、右键菜单、活动栏「导入导出」菜单、备份 / 恢复对话框、连接 / 库切换、新建连接、设置（带即时预览）、危险确认、SQL 预览、通知、提示卡 |

## 直接定位到某个状态

地址栏支持参数，方便截图和对稿：`index.html#page=export&exStep=2`、`#page=data&modal=backup`、`#page=sql&dock=ai`、`#page=data&menu=transfer:50:300`、`#theme=dark&scheme=A`。

## 可以试的交互

- `1` `2` `3` 切换方案，`T` 切换主题，`⌘K` 命令面板，`⌘,` 设置，`⌘I` AI，`⌘B` 收起侧栏。
- 双击数据单元格编辑，右下角会出现「待提交」条；右键行 / 表 / 连接卡片有菜单。
- ER 图里的表可以拖动；查询页的分割条可以拖。
- 「动效实验室」里的滑块会改写整个设计稿的动效速度。

## 交互细节（落地时要照做）

- 侧栏开关在活动栏底部（主题、设置上面），选中态与侧栏显隐一致；标题栏左边只有连接胶囊，标签条放不下时只在条内横向滚动，左右两侧的按钮永远在。
- 表页顶部「数据 / 结构 / DDL / 文档」分段：轨道高 26，和同一行的过滤条、按钮等高（按钮 22 + 上下各 2）。
- 文档页：右上「AI 补全注释」「复制 Markdown」；标题带表备注 chip，下面一句说明，字段表三列（字段 / 类型 / 说明）；AI 草拟的说明尾部带 ✦ AI。`#page=doc`
- 查询结果的列头和数据页一致：有类型的列带类型徽标 + 半粗列名，表达式列没有类型只有列名。
- 行预览头部「字段 / JSON」：JSON 页整行显示为带语法高亮的等宽文本。
- 切库浮层：宽度随最长的库名变化（最小 220、最大 340）；点库名弹出，再点一次（或点外面、Esc）收起；出场动画与连接浮层相同。

## 第三轮设计（待落地，代码还没动）

打开方式见上面的「直接定位」：`#page=data&modal=palette&q=or`、`#modal=wiz:ex`、`#modal=settings`、`#modal=tabsel&manyTabs=1`、`#menu=dbmore:130:90`、`#page=sql`。加 `&reduce=1` 可关掉动效再截图。

| 项 | 设计 |
| --- | --- |
| 数据库图标 | 各数据库用品牌 SVG（`scripts/dbicons.js`）：MySQL、PostgreSQL、SQLite、MariaDB、ClickHouse、SQL Server、TiDB 取自 Simple Icons（CC0），StarRocks 取自官方仓库 `StarRocks/starrocks` 的 `docs/docusaurus/static/img/logo.svg`（自带两种品牌色）。图标放在白底圆角块里（深色主题是浅灰底，品牌色才看得清），连接色变成块的细环。品牌图标是各数据库的商标，只用来标识该数据库的连接 |
| 连接胶囊（标题栏左） | 只有「图标 + 名称 + 环境标记 + 箭头」，宽度随名称、最宽 200；离红绿灯一个正常的间距（12px：红绿灯 14→66，胶囊从 78 开始），不额外留空；已打开的连接数挪进浮层标题，状态点不再画在胶囊里 |
| 标签太多 | 放不下时显示**最新的**（新开的标签滚到最右），前面的从左边慢慢淡出（左 / 右各 28px 渐隐），向左滑（触控板横滑 / 滚轮）才回得到前面去；切到哪个标签就把它滚进可视区。**只有真的放不下时**，右端才出现「⌄ N」按钮，点开「已打开的标签 · N」列表（可筛选、选中项高亮、悬停出 ×、改动过的带橙点、底部「关闭其他标签」）；放得下时按钮不出现 |
| 命令面板 | 800 宽，左边分组列表（44px 一行：图标块 + 标题 + 副标题 + 键帽），右边预览当前项（表：字段；历史：**语法高亮的 SQL** + 耗时结果；连接：地址版本；命令：说明与快捷键）；选中行用淡强调底 + 左侧竖线，不再整行实心；历史项在列表里也是高亮 SQL；`tab` 切换范围、`>` 只看命令 |
| 切库浮层 | 宽度随库名：最小 220、最大 340；安全级别不再单独占一行，改成库名右边的小标签（只读是黄色锁） |
| 侧栏当前库一行 | `库名 ⌃⌄ [安全级别]  …  新建库  更多`；侧栏底部的「新建表 / 导入 / …」整条去掉：新建表在「表」分组头右边的 + 和「更多」菜单里，导入导出备份也都在「更多」菜单（下面是安全级别单选） |
| 导入 / 导出 / 备份 / 恢复 | 统一成**弹窗向导**（820×600）：头部图标块 + 标题 + 一句话，横向步骤条（✓ 已完成、当前高亮、可点回去），中间内容，底部左提示右「上一步 / 下一步」。导出、导入各四步；备份「选项 → 位置 → 执行」，恢复「选择备份 → 目标与选项 → 执行」。入口：活动栏「导入导出」菜单、侧栏「更多」、命令面板 |
| 查询页 | 工具栏右上不再有库选择（库在侧栏切）；结果区自己的底栏取消，并进最底下的全局状态栏，两条合成一条：左边是 耗时 · 第 1–500 行，共 6,000 行 · 翻页 ‹ 1/12 › · 每页行数，右边是 在当前页中查找 · 固定 · 导出结果，再往右才是事务模式 / 环境 / 表数 |
| 排序等待流光 | 数据页加载和查询结果「点列头排序」共用：超过 500 ms 后，区域顶部出现 2px 流光条，等待中的列头同时铺一层流动的高光，结果回来立即消失。设计稿里点结果表头可以试 |
| 设置 | 960×640；左边分组导航（常规 / 工作区 / 安全与数据 / 智能 / 其他）带搜索，右边每页是页头（图标 + 标题 + 一句话）加卡片分区；外观页里主题是四张预览卡，布局是三张布局卡 |
| 键帽 | 全站一个形状（18px 高、5px 圆角、半粗 10.5px）；中性底用浅灰 + 细边 + 下沿一线，主按钮 / 淡强调按钮 / 选中行上用跟随前景色的半透明底、无边——彩色底上不再出现灰盒子 |

### 结构页与应用的核对结果

已逐项核对：拖动提示、行状态底色（新增绿 / 删除红 / 改动黄）、索引区与外键 / 触发器标签、底部修改条，应用里都已有；
顶部条的「备注」已补上（只读，显示库里的表备注）。仍有差别：**引擎**应用里没有（表信息里不带引擎，要加得先补后端）；
类型列设计稿是点开才出选择、应用每行带下拉箭头（受控件限制）；SQLite 不能调整列顺序，所以没有拖动提示。

### 需要你定的

- 查询页「底部状态栏」我按这个理解做的：**结果区自己的底栏取消**（查找 / 固定 / 导出进结果标题栏），**全局最底下的状态栏保留**（它承担耗时 · 行数、事务模式、环境、表数，数据页的翻页也在那里）。如果你是想把最底下的全局状态栏整条拿掉，告诉我，翻页和事务模式要换地方放。
- 品牌图标属于各数据库的商标，只用于标识该数据库的连接；TiDB、StarRocks 要等官方 SVG。

## 第四轮设计（待落地）

| 项 | 设计 |
| --- | --- |
| 悬浮提示 | 深色气泡（深底浅字，深色主题反相）：圆角 8、内边距 5×9、11.5px 中等字重、2 级阴影，离触发元素 6px，放不下翻到上方。三种写法：纯文字、文字 + 快捷键键帽（末尾的 ⌘T 自动拆成半透明键帽）、标题 + 说明（说明 11px、70% 不透明、最宽 260 换行）。悬停 450ms 后淡入（缩放 .96 + 上移 2px，120ms）；300ms 内从一个换到另一个不再等；离开 80ms 淡出；按下 / 滚动立即消失。图标按钮必须有提示。样例见设计系统「组件库」 |
| 组件库 | 设计系统新增「组件库」页：按钮（类型 / 三档尺寸 / 状态）、输入、开关勾选单选、分段与标签、标记、悬浮提示、菜单、提示卡与进度；落地时 Go 控件要和它一致 |
| 动效 | 见设计系统「动效实验室」规范表：左侧栏宽度 0↔236 + 内容淡入淡出（220ms）；右侧停靠栏进 220ms / 出 160ms（右 16px + 淡）；模态进 220ms 回弹（缩放 .96、上移 8px、背景模糊）/ 出 120ms；锚定浮层进 160ms / 出 80ms；提示气泡 120ms；新标签宽度 0→自然 160ms。设计稿里收起侧栏、关闭停靠栏、关闭弹窗都会播出场 |
| 响应式工具条 | 窗口（或右边停靠栏）把内容区挤窄时，数据页顶栏**只收一部分、按优先级逐级收，绝不整条收成一个「»」**：① 文字标签（列 6/6、SQL）只剩图标 → ② 筛选条缩短、去掉键帽和长提示 → ③ 次要图标按钮（新增、删除、行预览）收进「…」菜单。视图分段（数据 / 结构 / DDL / 文档）、筛选条、刷新永远在。阈值按工具条自己的宽度：920 / 780 / 640。试：`#page=data&dock=ai` |
| 命令面板 | 范围标签六枚等分整行宽度；↑↓ 移动选中项时左列表跟着滚到可见；右预览头部固定、正文自己滚（字段多、SQL 长都能看全）；选中竖线画在行内侧；底栏键帽等高 |
| 备份 / 恢复 | 同导入导出的统一向导（见上），各三步，代码照着落地 |
