# MiniDB 界面规范

界面是 [MyGo](https://mygo.run/) 的原生 UI（纯 Go、立即模式）。这份文档记录视觉与交互上已经定下来的规则，新增界面时照着做，不另起一套。具体的数值和颜色以 [UI_TOKENS.md](UI_TOKENS.md) 和代码为准：`internal/ui/theme_*.go`（令牌与尺寸）、`internal/ui/btn.go`（按钮）、`internal/ui/tabstrip.go`（标签）、`internal/ui/grid.go`（数据网格）。

## 1. 气质

桌面数据库工具：信息密度高、层级清晰、克制，参考 TablePlus 和 macOS 的工具软件。数据安全感优先——危险操作要能一眼认出来，并且要二次确认。

不要做：营销页式的大图大字、大面积渐变装饰、卡片套卡片、为普通区域加大圆角。

## 2. 令牌

颜色、字号、尺寸的**全部数值**在 [UI_TOKENS.md](UI_TOKENS.md)（唯一来源），代码实现是 `internal/ui/theme_tokens.go`、`theme_palettes.go`、`theme_metrics.go`，两边由 `TestTokensMatchDocs` 对账。业务代码只引用令牌，不写 `ui.Hex(...)`，不在调用处写字号和控件高度的数字（`TestUINoHardcodedStyle` 守着）。

| 类别 | 规则 |
| --- | --- |
| 配色方案 | 石墨（默认，冷灰 + 靛蓝）/ 纸墨 / 极光，只改变表面、文字、线条和强调色；状态色、语法色、图表色三套共用。默认主题是浅色（设置里可选深色、跟随系统） |
| 底色层级 | `surface`（内容区）→ `surfaceSecondary`（标题栏、活动栏、侧栏、状态栏、条栏）→ `surfaceTertiary`（轨道、悬停底）→ `surfaceElev`（浮层）；层级靠明度，不靠加线 |
| 强调色 | `accent`，**固定，不跟随连接颜色**（配色方案石墨 / 纸墨 / 极光三选一，设置 → 字体与主题）。连接颜色只出现在连接头像和生产环境的顶部 3px 色带上 |
| 文字 | `fg` / `fgSecondary` / `fgMuted` 三档 |
| 状态 | `success` / `warning` / `danger` / `info`，各有淡底 `xxxBg`（芯片、提示条）；禁用只降透明度，不改布局 |
| 分隔 | 边框优先于阴影：`border`（区域分隔、控件描边）、`borderSubtle`（卡片内部细线）；阴影只给弹窗、菜单、浮层，深色下阴影看不见，所以对话框、菜单、提示都再描一圈 `border` |
| 线条对比度 | `theme_contrast_test.go` 按三套配色的明暗两面守着区间（`border` 对内容区约 1.2～1.45:1，`borderSubtle` 约 1.08～1.25:1），不能把某一套的线单独调重 |
| 表格行 | 默认**细行线**，不铺斑马纹；`stripe` 只在设置里选了「斑马纹」时才用。行状态整行铺色：`rowNew` / `rowDelete` / `cellEdit` |
| 分段开关 | 轨道 `segTrack`、滑块 `segThumb`，滑块总比轨道更「凸」 |
| 语义色 | 图标按对象着色（表蓝、视图紫、查询绿、主键与函数橙，`iconColor`）；值按类型着色（数字蓝、时间青，`valueColor`） |

尺寸（DIP）：标题栏 40（`sizeToolbar`）、活动栏 44、侧栏 236、状态栏 26、条栏 34；控件只有 22 / 26 / 30 三档（`sizeBtnSm` / `sizeBtn` / `sizeBtnLg`）；输入框 26（对话框里 32）；行高 26、表头 28；标签 32；字号正文 13、控件 12.5、密集信息（表格、标签、侧栏）12、辅助 11；圆角控件 6、面板 10、对话框 12；间距以 4 为单位。表格、SQL、标识符用等宽字体 `mono`，其余用界面字体。

## 3. 按钮与基础控件

按钮只有三个层级，高度、字号、图标、内边距各自固定，**不要在调用处单独设 `Height` / `FontSize`**：

| 函数 | 用在 | 内容 |
| --- | --- | --- |
| `actBtn` / `actPrimary`（22） | 面板、列表、工具栏里的操作 | 图标 + 文字 |
| `fieldBtn` / `fieldPrimary`（26） | 和 26px 输入框同排 | 图标 + 文字 |
| `footBtn` / `footPrimary`（30） | 对话框底部的取消、确认 | 纯文字 |

换皮变体在 `btn_kinds.go`：`softBtn`（强调淡底，推荐动作如「AI 优化」）、`ghostBtn`（无底，弱操作）、`dangerSoftBtn`（红淡底，删除入口）、`dangerBtn` / `dangerFootBtn`（红底，二次确认里的最终删除）。**一屏只放一个主按钮**。

只有图标的按钮用 `tipBtn` / `toggleBtn`，必须带悬停提示；有快捷键的提示里带上 `keyHint`。

其他基础控件（`ctl_*.go`，对照设计稿「组件规范」，`ctl_test.go` 里有尺寸断言和浅/深色画廊截图）：

| 控件 | 函数 | 规则 |
| --- | --- | --- |
| 芯片 | `chip` / `sqChip` | 状态标签，高 20 / 方角 18（环境标记 PROD、DEV）；颜色只表达状态：中性、成功、警告、失败、提示、强调 |
| 按键帽 | `kbd` | 快捷键提示 ⌘ ⏎ |
| 分段开关 | `segmented` / `pillTabs` | 切换**同一份数据的视图**（数据 / 结构 / DDL）；段高 22，轨道圆角 7，选中段带细阴影 |
| 下划线标签 | `ulTabs` | 切换**同级的不同内容**（索引 / 外键 / 触发器），带计数；选中项下压 2px 强调色线 |
| 输入框 | `ui.TextInput` / `SearchField` | 高 26（对话框里的表单 32，`sizeInputLg`）；聚焦描强调色，错误描 `danger` |
| 开关、复选、单选 | `ui.Switch` / `ui.Checkbox` / `ui.Radio` | 选中都用强调色，由窗口主题统一着色 |

浮层（对话框、菜单、提示卡）用边框 + 阴影分层：对话框圆角 12，菜单与提示卡 9；悬浮提示是反色小气泡（主文字色做底），圆角 5，不描边；提示卡 `toastCard`：图标、正文、可选操作按钮，右上角叠放最多三张。

## 4. 标签

两类标签，别混用：

- **主标签栏**（标题栏里，`tabbar.go`）：标签可以关闭（悬浮出现 ×，未保存时显示圆点，中键关闭），右端有「＋」新建查询；
- **页内下划线标签**（`ulStrip` / `ulTabs`，`ctl_tabs.go`）：表页顶栏的 数据 / 结构 / DDL / 文档、结构页下半区的 索引 / 外键 / 触发器、查询结果区的「结果 N / 消息 / 执行计划」都是它。条栏高 `sizeBar`（34），选中项文字用主文字色、下压 2px 强调色线，标签后跟灰色计数，底下一条 1px 分隔线；不能关闭的条栏用 `tabStrip`（`counts` 是计数，`trailing` 放靠右的操作按钮）。

底部的 Data / Structure / DDL / Doc 和侧栏顶部的「项目 / 查询 / 历史」是另一类：`pillTabs`，圆角分段开关（侧栏里 `grow` 为真，三段等分整行、更高一些）。

## 5. 表格

**待提交悬浮条**（`pendingbar.go`）：表里有没提交的修改（数据或结构）时，浮在内容区底部正中，样式是设计稿 A 的「岛」——深色胶囊（底色用前景色 `fg`，字用 `surface`，深色主题下自动反相），按钮是透明的胶囊，主按钮用强调色：`● N 项待提交  改 1 · 增 1 · 删 1 | 预览 SQL | 丢弃 | 提交 ⌘S`。它是修改的唯一入口，标题栏和底栏都不再放丢弃 / 提交；没有修改时不占位。浮条放在 `tableTab.view` 的内容层里（相对内容定位，不压底栏）。


数据网格和结构视图都建在 `ui.Table` 上，共用同一套外观：

- 主题：`gridSpacing`（让表头正好 `sizeHead`=28）、单元格 12px 等宽字、表头 12px 界面字体次要文字色；行高是 `gridRowH`（默认 `sizeRow`=26，设置里选「标准」时是 `sizeRowComfy`=30，由 `applyLookPrefs` 写入），所以下方的行线 / 斑马纹（`paintGridBg`）能对齐；
- 行样式：默认每行底下 1px 细行线（`borderSubtle`，数据行的线由 `cellBox` 画、跟着滚动，数据行下面的空行由 `paintGridBg` 补），设置里开「斑马纹」才换成隔行底色（`showZebra`）；
- 数值列（`isNumericType`）表头和内容都靠右（`numRightAlign`，`cellBoxAt` 的 `end`）；
- 列宽拖表头边缘调整，列序拖表头挪动，双击边缘按内容适配；
- 补满与类型：各列比表格窄时，显示顺序里最右的可伸缩列吃掉剩余宽度（`grid_fill.go`，用户拖过它的宽度后不再撑）；列头是「类型徽标（`typeBadge`，整数 123 / 小数 1.0 蓝、文字 Aa 绿、时间时钟灰）+ 加粗列名 + 主键钥匙 + 排序箭头」（`grid_head.go`，非 plain 的网格才画；列的 `Title` 此时留空，名字由 `headerCell` 画，`ID` 仍是列名）；
- 行状态用整行底色：新增偏绿、待删除偏红、选中偏强调色（`cellBox` 的 tint 会盖满单元格含内边距，行内没有缝）；
- 选中行不要整行刷成实心强调色（里面的输入框、勾选框会看不清）：给表格换一份"淡强调色"的主题，网格里的控件另用原主题。

### 结构视图（`structview.go`、`objects.go`）

- 上半区是列的网格，**就地编辑**（名称、类型、可空、默认值、备注都是单元格里的控件）；新增行铺绿、待删除行铺红；
- 输入格（名称、类型、默认值、备注、索引名 / 列）点进去拿到焦点时，整个单元格描一圈强调色外框，和数据网格的单元格编辑一致（`ringCellBox` / `paintEditRing`，在 `cellring.go`）；
- MySQL 系数据库可以**拖动行上下换位**调整列序（`ListState.Reorder`，生成 `AFTER` / `FIRST`）；SQLite、PostgreSQL 改不了列序，不给拖动；
- 上半区的区段头「列 N」+ 右端「添加列」，下半区用 `tabStrip` 切换 索引 / 外键 / 触发器（计数灰色），标签栏右端是当前这一项的「添加」按钮；上下两块之间的分隔条可以拖；
- 有修改时底部悬浮条按结构语义分项：「加列 1 · 改列 1 · 加索引 1」，按钮是「预览 ALTER」「应用」（`structParts`）；
- **索引、外键、触发器都就地编辑，不弹窗**（参照 TablePlus）：「添加」在表格末尾多一行，名称格拿到焦点；名称留空时自动取 `idx_表_列` / `fk_表_列`；
  - 已有的索引、外键也能直接改，提交时先删旧的再建新的（`modified` 状态）；改成空名称 / 空列的索引保持原样，不会误删；
  - 触发器：新增的在单元格里填名称、时机、事件，触发的内容写在右侧编辑器；已有的只能改语句（右侧是完整的 `CREATE TRIGGER`），提交时先删后建；
  - 删除只是标成待删除（红色，可撤销），和列一样等 ⌘S 统一提交；提交顺序是：删旧的外键 / 触发器 → 改列和索引 → 建新的外键 / 触发器（`BuildFullStructureStatements`）；
  - SQLite、StarRocks 不能改已有表的外键，外键页只读；
- 横向滚动到底时，Table 的滚动区右侧还剩一条约 14px 的轨道，单元格铺不到；补满列的单元格画完会登记自己的位置，下一帧由表格这一层把行底色接着铺到边缘（`rowtail.go`），整行才连成一片；
- 数据行在开了斑马纹时隔行铺底（库自带的斑马纹要开单元格选择，和拖动排序冲突，所以由 `structRowTint` 在单元格里铺），选中的行不铺；
- 选中行后 ⌫ / Delete 删除；右键菜单有上移、下移、删除；提交走 `commitStructure` → `safeGate`，⌘S 提交。

- **窗口骨架**（设计稿的布局 B，`layout.go` 拼装）：
  - 标题栏 40px（`titlebar.go`）：左边是侧栏开关和连接胶囊（`titlebar_conn.go`，点开「已打开的连接」浮层），中间是标签（标签并进标题栏，`tabbar.go`），右边是搜索图标（⌘P；⌘K 是切换数据库）、控制台、AI、通知；
  - 活动栏 44px（`railbar.go`）：项目 / 查询 / 历史三页，下面是项目概览、ER、监控、用户、导入导出，底部是主题和设置；原来 60px 的工作区栏**取消**，多个连接靠标题栏的连接胶囊弹层切换（`conn_popover.go`、`workspaces_popup.go`）；
  - 侧栏 236px：顶上是「当前库」一行（`db_header.go`：库名 ⇅ + 新建数据库 + 更多）+ 可能出现的安全模式芯片 + 筛选框（筛选框一直在，⌘⇧F / ⌘F 聚焦它），底栏 34px；
  - 状态栏 26px（`statusbar.go`）在内容区最下面：连接状态、事务条、索引、后台任务、更新提示、待提交；
  - 生产环境（标签为 production）整窗顶上有一条 3px 红带（`envband.go`）。

- **表页顶栏与状态栏**（`table_topbar.go`）：表页自己的顶栏左边是灰色圆角分段 数据 / 结构 / DDL / 文档（`viewSeg`，`table_seg.go`），数据页紧跟着是筛选组（`filter_pop.go`：没条件时「添加过滤… ⌘F」，有条件时是条件芯片；点它或 ⌘F 弹出筛选浮层，应用后收起），右边按页签给操作（数据页：筛选、列、新增、删除、SQL、行预览、刷新）；行范围「第 1–500 行，共 N 行」和翻页放在全局状态栏的右侧（`tabStatus`），不再占表页底部一条。
- **查询页**：工具栏是「执行 ⌘⏎ | 执行计划 | 格式化 | 收藏 | AI 编辑」带文字的按钮，其余图标按钮在右端；结果区有 34px 标题栏（`query_head.go`）：左边是「结果 N / 消息 / 执行计划」下划线标签，右边是「数据 / 图表」分段开关（仅当前结果能出图时出现）；底部状态条是耗时、行数（或翻页）、结果内查找、导出结果。

### 表级操作

- **新建表**（`tablenew.go`）：侧栏底部「…」菜单 →「新建表」，开一个只有结构页的标签（不进会话）；表名填在结构页顶部的「表名」格，预先有一列 `id`（自增主键），列、索引像编辑已有表一样就地填，新建表时多出「主键」「自增」两列；⌘S 一次建出，建好后变成这张表的普通标签。外键、触发器要建好之后再加；
- **重命名**：已有的表改结构页顶部的「表名」格，随 ⌘S 一起提交（先改列和索引，最后 `RENAME`），标签、侧栏固定项同步改名。视图和只读连接里这一格只读；
- **清空 / 删除表**：确认框里按数据库给复选项——PostgreSQL 有「重置自增序列」「CASCADE」，其余库没有（`database.TableOpSupport`）；SQLite 没有 TRUNCATE，清空用 `DELETE FROM`；
- 鼠标在左侧栏上时，⌘F 搜索的是侧栏的列表（表、查询或历史，停在哪一段就搜哪一段）；在别处仍是数据表的过滤条（⌘⇧F 始终是搜侧栏的表）；
- 侧栏列表的行：鼠标扫过是灰色底（`p.hover`），点选后是强调色淡底，两者不同；
- 侧栏点选一张表后，⌥⌫ 清空、单按 Delete 删除（视图则删除视图），都先确认。键盘归选中的那一行，不是整个列表。

- **项目概览**（`overview.go`、`overview_cards.go`）：顶上四张汇总卡（表 / 视图 / 总行数 / 数据大小，`summaryCards`）和「全部 / 表 / 视图」筛选条，下面把当前库所有表和视图列成一张表，数据大小列带比例条（`dataSizeBar`）（名称、类型、引擎、行数、数据 / 索引大小、排序规则、备注、创建 / 更新时间，取不到的显示「—」）。入口：侧栏「表」「视图」标题悬停时右端的图标、右键标题、右键任意一张表、底部「…」菜单。点表头三态排序，右上角筛选名称和备注，双击或回车打开那张表，右键和侧栏的表一致。MySQL、PostgreSQL 的行数是估算值（底部有说明），SQLite 是精确值。每个工作区只有一个概览标签，表增删改名后自动刷新，会进会话。

### AI 助手的回答

回答按 ReAct 的过程**按发生的顺序**一路排下来（`assistant_message.go` 的 `timeline`），不收进折叠的块：推理 →（说明文字）→ 工具调用 → 这一步的结果 → 再推理 → 再调下一个 → 最后一段文字是回答。

- 推理：正在想时展开，标题「思考中 · N 秒」，文字实时流在一条左边线后面；想完收成一行「思考了 N 秒」，点开回看（耗时记在 `agent.Part.DurationMs`，随会话保存）；
- 每一步的标题行：图标块 + 名称 + 对象，右侧是状态（转圈 / 摘要·耗时 + 绿色对勾 / 红色叉），最右的展开箭头悬停才显出、展开时转 90°；新的一步用 `stepTransition` 轻轻淡入，状态图标用 `popTransition`；
- **思维链从哪来**（`internal/ai`）：Responses 的 reasoning summary / reasoning text 事件；Chat 分片里的 `reasoning_content`、`reasoning`、`thinking`、`reasoning_details`；以及正文开头行内的 `<think>…</think>`（`thinkSplitter`）。模型本身不输出推理（如 `deepseek-chat`）时界面上就没有思考行，日志里每轮的 `reasoning_len=0` 可以确认；
- 工具：一行标题（图标、名称、对象、摘要和耗时，运行中转圈），点开是参数、语法高亮的 SQL 和结果。**运行过程中**失败的自动展开（原因 + 建议），最近一次返回了数据表的数据类工具也展开；**回答完成后所有工具自动收成一行**，只留回答（出错没有回答时不收）；
- 回答里的 SQL 代码块点「执行」：块里的语句拆开后全部执行，每条一个结果页；
- 等下一步（还没动静、或刚拿到一个结果还在想）时末尾有一行「思考中…」；
- 没有单独拎到回复外面的「结果卡」，结果总在它那一步后面，和模型的说明对得上。

### 查询结果的翻页

没写 LIMIT 的 SELECT / WITH 查询一次只取一页（默认 500 行，设置 → 编辑器的「结果行数上限」可改），底栏显示「第 1–500 行，共 N 行」，旁边是上一页 / 下一页、第几页 / 共几页和每页行数（100～10000）。翻页只重新执行这一条语句（`gotoPage`），行号接着上一页数，控制台日志里能看到对应的 `LIMIT … OFFSET …`；自己写了 LIMIT 的语句、以及 SHOW / EXPLAIN 这类非 SELECT 的不分页。导出结果仍是不限行数的完整结果。

### 行预览与历史

- **行预览停靠栏只有一份**（`rowpane.go` 的 `rowPane`，默认宽 `sizeRowPane`=300，背景 `surfaceSecondary`）：表数据页和查询结果页都用它。头部（`rowpane_head.go`）是「行 N」+ 表名 + 字段 / JSON 分段开关；字段页字段名在左、类型在右，JSON 字段用带语法高亮的编辑器；JSON 页把选中的行整个按 JSON 显示。差别只在 `paneSource`：表数据页能就地改值、字段右端有下拉菜单；查询结果页只读、没有下拉箭头。新增行预览的功能改这一处，不要在两边各写一份；
- 行预览和 Quick Look 里的 JSON 编辑器不显示括号配对的描边（`noBracketMatch`），括号和别的字符一样正常显示；
- **历史只在侧栏**：「历史」页按天分组，每天一个可折叠的标题（今天、昨天，其余写日期，折叠状态记在 `side.collapsed["day:日期"]`）；「查询」页（收藏）仍是平铺列表。查询器里不再有自己的历史图标、弹窗和 ⌘Y；「清空历史」在侧栏底部「…」菜单里（历史页才有，收藏的语句保留）。

### 欢迎页、连接表单、命令面板与弹层

- **欢迎页就是空工作区**（`welcome_page.go`、`welcome_cards.go`）：没有打开的连接（`len(s.spaces)==0`）时显示，头部有「卡片 / 列表」切换、搜索框（↑↓←→ 移动、⏎ 连接、⌘F 聚焦）、导入与新建；连接按文件夹分组，卡片每行 `welcomeCols`=3 列；拖拽排序、拖进文件夹、右键菜单沿用 `connMenu`。已有工作区时「连接管理」仍是对话框（`conn_list.go`），两处共用同一份数据与菜单。分类栏顶部是「全部连接 / 最近使用 / 已固定」，后两个是保留视图（`welcome_recent.go` 的 `viewRecent` / `viewPinned`，借用 `layout.connFolder` 存），数据来自 `ConnectionConfig.LastUsed`（连接成功时由 `ConnectionService` 记）和 `Pinned`（右键菜单固定 / 取消固定）；文件夹标题带折叠箭头，点一下折叠；卡片右上角的环境标记是大写简称（PROD / STG / DEV…，`tagShort`），地址后面附 · 只读 · SSH，底行是绿点「已打开」或最近使用时间（`agoText`）。
- **新建 / 编辑连接对话框宽 700**（`conn_form.go`、`conn_form_tabs.go`、`conn_type.go`）：顶部是 8 列数据库类型网格（`typeGrid`），下面是「常规 / SSH / SSL / 高级」下划线标签，输入框一律 `sizeInputLg`（32），底部「测试连接」在左，「保存」「保存并连接」在右。从欢迎页打开（`fromPage`）时保存、返回、删除都直接关闭，不再回到对话框列表。
- **命令面板**（`palette.go`、`palette_parts.go`）：输入框右端有 esc 键帽，选中行是强调色实心底配 `accentFg` 文字，表行说明带估算行数（「shop · 12.4k 行」）；顶部是范围芯片（全部 / 表 / 视图 / 查询 / 命令 …），结果按组显示；以 `>` 开头只搜命令；有工作区且输入非空时末尾固定一行「问 AI “…”」，回车把问题交给 AI 面板；底栏提示 ↑↓ 选择、⏎ 打开、⌘⏎ 新标签页。
- **连接浮层与切库浮层**：标题栏连接胶囊点开「已打开的连接」（`conn_popover.go`，宽 `sizeConnPop`，每行头像 + 名称 + 环境标记 + 类型版本 · 地址 + 状态点 + ×，底部打开 / 新建连接；`workspaces_popup.go` 里 `wsPopup.anchored` 为真时走它，否则仍是居中弹层）；侧栏库名点开切库浮层（`db_popover.go`，宽 `sizeDbPop`，搜索 + 库行「大小 · N 张表」+ 新建数据库，状态沿用 `s.sw`，`dbSwitcher.anchored` 为假即侧栏收起时回退成居中对话框）。选中行用 `accentSoft2`，当前项加粗。

- **危险操作与反馈**：确认框（`confirm.go`）宽 380，头部是 28px 圆形图标 + 标题，危险操作用 `dangerFootBtn`、默认焦点在「取消」、⌘⏎ 确认；要展示语句用 `askWarnCode`（等宽代码框）。事务进行中、连接断开是内容区顶部的整条提示（`banners.go`），按钮就在条上；提示卡（toast）在右下角、状态栏上方，新的在最下面。
- **外观偏好**（`prefs_look.go`）：配色、密度、行样式、数字对齐、NULL 样式都是 `lookPrefs`（并进 `uiPrefs`，JSON 平铺），靠 `Shell.applyLookPrefs` 写进全局绘制开关（`activeScheme`、`gridRowH`、`showZebra`、`numRightAlign`、`nullStyled`）；新增外观选项照这个路子加字段，不要再往 `settings.go` 里堆（它有行数上限）。

## 6. 对话框与危险操作

- 对话框统一用 `Shell.dialog`，表单项用 `dlgField`，底部 `footBtn` / `footPrimary`；
- 删除、清空等不可恢复的操作用 `askDanger`（默认焦点在"取消"）；会丢失未保存内容的用 `askWarn`；
- 写库操作经过 `safeGate`（安全模式：静默 / 确认 / 密码），并写入控制台日志；
- 反馈用 `toastOK` / `toastErr` / `toastWarn`，不要用弹窗报告普通结果；
- **弹层背景**（`modal.go`）：对话框背后是 30% 暗幕 + 2px 模糊（`sizeScrimBlur`，用 `glass.Blur` 材质），面板带「缩放 + 淡入」的入场；点暗幕外关闭。
- **标题栏拖动**：标题栏里所有空白处都要 `DragWindow()`，每层铺满的容器都得是拖动柄，否则中间那层会吃掉点击；欢迎页的自绘标题栏（`welcome_titlebar.go`）同理。
- **动效**（`motion.go`）：入场姿态统一用 `enterPose`（页面自下滑入、弹层缩放淡入、提示卡右滑），时长取 `motionFast` / `motionSlow`；系统开了「减弱动态效果」时 `enterPose` 直接跳过，测试环境也默认开着它，所以截图和断言不会受第一帧姿态影响。
- **导出 / 导入向导**（`transfer_*.go`）：不是对话框而是工作区标签（`transferTab`）。左边 170px 步骤条（当前步强调色圆点，走过的打勾，可点回去，「执行」步要开始后才能进），右边是当前一步，底部是上一步 / 下一步；表单状态放在 `Shell.exp` / `Shell.imp`，进度来自总线任务事件（`xferRun`，事件比任务号先到时靠 `pending` 补上）。「导出查询结果」仍是对话框（`exportview.go`）。
- **备份 / 还原对话框**（`dump_view.go`）：标题前是图标方块（`dlgTile`），表单行用 `dlgRow`（右对齐标签 + 控件），风险提示用 `dlgNotice` 琥珀色条。

## 7. 国际化

所有用户可见的文字都进 `locales/zh-Hans.json` 和 `locales/en.json`，然后 `go tool mygo generate`，代码里用生成的 `locales.Xxx()`。提交前 `go tool mygo i18n check` 要通过。不再被引用的键要及时删掉。

## 8. 快捷键

窗口级快捷键由 `keymap.go`（按键组合与配置名）和 `shortcuts.go`（统一处理，焦点在哪里都生效）负责，用户可以在设置 → 快捷键里改；新增命令先登记再接处理函数，不要在视图里零散地写全局 `Shortcut`。只在某个元素有焦点时才生效的按键（如表格里的 ⌫）用该元素自己的 `Shortcut`，这样焦点在输入框时按键归输入框。

## 9. 编码约定

- 视图函数每帧都会执行：**不做 I/O**，阻塞操作放进 `uiThread.bg`，结果回到 UI 线程；
- 元素要有稳定的 `c.Key(...)`：位置变化会让 `AutoFocus` 抢走焦点；
- 依赖方向 `ui → app → 领域层`，`app` 和领域包不引用 `mygo/ui`；
- 注释用中文，说明"为什么"，不复述代码。

## 10. 测试与验收

- 界面用 `ui.Tester` 无窗口地跑（`newEnv`、`openWorkspace`、`e.tt.*`），`go test ./...` 覆盖交互；
- `MINIDB_SHOTS=<目录> go test ./internal/ui -run <名字>` 会把 `e.shot(...)` 的截图写成 PNG，改完界面务必看一眼；
- 验收清单：浅色 / 深色都看过（`MINIDB_SHOTS=<目录> go test ./internal/ui -run TestShotsThemes` 会把同一组界面在两种主题下各渲染一遍，方便对照线条）；中英文都不截断；`go vet ./... && go tool mygo vet .`、`go tool mygo i18n check`、`go test ./...` 全部通过；新增行为有对应测试。

## 状态记忆

关闭前是什么状态，重新打开就是什么状态（每 8 秒和退出时存，`SaveState`）：

- 窗口大小和位置：窗口的 `StateKey`；
- 打开的连接、每个连接的标签页（含查询草稿、表标签的子视图和行预览开关）、前台标签、AI 面板开关：`session.go`；
- 侧栏停在哪一段、折叠了哪些分组：同在工作区会话里；
- 侧栏、AI 面板、行预览栏拖出来的宽度，侧栏是否收起，日志面板是否打开及高度：全局布局 `layout_state.go`，新开的工作区也按它来。

新增一个「拖得动 / 开关得了」的界面状态时，要顺手加进这里。

## 快捷键与功能入口

- 快捷键的默认值对齐 TablePlus 的 Keymap 文档（打开连接 ⇧⌘K、显示数据/结构 ⌃⌘[ ⌃⌘]、切换窗格 ⌥⌘[ ⌥⌘]、注释 ⌘/ ⌥⌘/ 等）。设置页分 全局 / 导航 / 数据表 / 编辑器 四组，点一下快捷键再按新键，录制时按 Delete 清空；
- **新增命令只在 `keymap.go` 的 `commands` 登记一次**，动作写进 `command_run.go`；编辑器自己处理按键的（运行、格式化、注释……）要加进 `editorHandled`，并在 `queryBindings` 里让位或绑定；
- 每个功能至少要有一个**看得见的入口**（按钮或菜单项），快捷键和命令面板只是补充：
  - 监控（概览 / 进程 / 慢查询）：顶栏的监控按钮、侧栏底部「…」菜单、菜单栏「查询」、⌥⌘M；进程列表是监控窗口的「进程」页，⌘. 直达；
  - 项目概览、ER 图、新建表、数据库内搜索、导入导出、用户、备份恢复：侧栏底部「…」菜单；
  - 跳到列、显示哪些列：底栏的列按钮、菜单栏「视图」、命令面板；
  - 手动提交（事务模式）：顶栏安全模式旁的开关（⌥⌘T），开启后出现「提交（⌥⌘S，⌘S 在没有表格修改时也提交事务）/ 回滚（⌥⌘Z）」和未提交条数；菜单栏「查询」、命令面板同样有。状态在 `database.ManualTx`，界面每帧只读内存快照，不做 I/O；关闭工作区、断开、切库前有 `txGuard` 确认。
- 列表里的列头（监控的慢查询、进程）用 `sortHead` + `sortSpec`：第一次点击按该列的默认方向（数值/耗时列先大后小），再点翻转，第三次回到数据来源的顺序；

## 设置页与「关于」

- 设置项**一组一张卡片**（和「编辑器」页一样）：卡片里每项一行，左边名称加一句说明、右边是控件（下拉、开关、按钮），项与项之间一条细线（`settingsGroup` 的 `row`）；输入框、主题卡片这类宽控件名称在上、控件在下，也在卡片里（`wide`）。不要一项一个框——框里只有一个标题、右边空着很难看；
- 「关于」页：图标、名称、版本和平台；更新状态卡（检查、下载进度、重启更新、自动下载开关）；仓库、更新日志、反馈、许可的链接；数据和日志目录；复制版本信息；版权。

## 发版与自动更新

- 版本号在 `mygo.json` 的 `version`；`CHANGELOG.md` 里必须有对应的 `## x.y.z` 小节（更新窗口显示它）；
- 发版**全程在本机**，不走线上 CI：改版本号和更新日志 → 提交 → 运行 `scripts/release.sh`。它会跑测试、本地构建并签名（`mygo build -platform darwin/universal -upload`）、上传到草稿 release、打 tag 并推送、再发布成最新版（发布后用户才能更新到）。`DRAFT_ONLY=1` 只上传草稿，到页面检查后手动发布；
- 更新用 `mygo.json` 里 `updates.publicKey` 对应的私钥签名：私钥在本机 `~/Library/Application Support/mygo/update-keys/`，**丢了就再也发不了更新，务必备份**；
- 应用自己管更新流程（`updates.go`，用 `mygo.Updater`）：启动 10 秒后和之后每小时在后台检查（不弹窗），发现新版本**自动下载**（设置 → 关于里可关），下载好后弹一条带「重启更新」按钮的消息，主界面右上角也留着「新版本 x · 重启更新」，点一下重启进入新版本；自动下载关闭时提示是「点击下载」。开发版和没配更新源的构建不检查，「关于」页会如实说明。

### 右键菜单与图标

- 菜单统一画在窗口内（`theme.go` 里 `SetMenuPresentation(ui.PopoverMenus)`），不用系统原生菜单；条目用 `menuItem` / `dangerItem`（`menu_icons.go`）带图标、快捷键提示，危险项红色。
- 强调色可在 设置 → 外观 里选（`theme_accent.go`），默认 indigo；强调色固定，不跟随连接颜色。
